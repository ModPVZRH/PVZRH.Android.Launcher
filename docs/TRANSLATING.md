# Translation Guide

Thank you for your interest in translating PVZRH Launcher! This guide will help you get started.

## Getting Started with Crowdin

We use [Crowdin](https://crowdin.com/project/pvzrh-launcher) to manage translations.

1. Go to [crowdin.com](https://crowdin.com/) and sign up
2. Contact the developer to get write access:
   - Discord: **elinmei0710** / **librahp_0928**
   - QQ: **2558527373** / **718038005**
3. Find our project: [pvzrh-launcher](https://crowdin.com/project/pvzrh-launcher)
4. Select your language and start translating

Crowdin parses XML files into translatable segments and highlights missing translations. You can see diffs when source files change.

## Translation Guidelines

### File Format
- Keep the XML structure intact
- Do not translate technical identifiers (string `name` attributes)
- Keep format specifiers (`%s`, `%d`, `%1$s`, etc.) in the same order

### Tone
- Use a friendly, helpful tone
- Keep translations natural and idiomatic

### Technical Terms
Some terms are kept in English even in translations:
BepInEx, .NET, libunity, IL2CPP, Git, GitHub, DLL, APK
